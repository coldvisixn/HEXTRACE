# Проверки MVP — 2026-10-14

## Проверенное окружение

Debian 13 x86_64, системный Python 3.13.5, Debian PySide6 6.8.2,
Nmap 7.95. Графические проверки выполнялись с `QT_QPA_PLATFORM=offscreen`.
Системные deb-зависимости распакованы в пользовательский prefix; root-установка
недоступна. Python/Qt/Nmap не включены в пакет приложения.

## Функциональные результаты

9 тестов, 9 passed, 0 skipped, 0 failed (7.189 s):

- SQLite: изоляция проектов, валидация IP, постраничная загрузка и повторное открытие.
- XML: открытые сервисы, пропуск down/closed, повторный импорт без дубликатов,
  сохранение координат и пользовательских заметок.
- Невалидный XML откатывает импорт целиком.
- GUI: восстановление карты и размеров панелей.
- Реальные события мыши: wheel zoom, middle-button pan, drag с сохранением позиции.
- Ограничение логов, включая вывод без переносов строк.
- Валидация IP и Custom ports; отказ от параллельного второго сканера.
- Настоящий QProcess/Nmap сканирует локальный HTTP fixture и создаёт Host/Service.

Внешние адреса и HTB-машины не сканировались.

`python3 scripts/check_package.py` проверил именно распакованный код deb,
создание проекта/узлов/связей и восстановление карты. Настоящий launcher из
пакета запустился с `/usr/bin/python3` и системными PySide6-модулями и создал
ожидаемую SQLite-схему. Desktop entry и SVG присутствуют в пакете.
Это не заменяет установку через apt и регистрацию в меню целевого desktop.

`scripts/setup_cloud.sh` проверен с пустым prefix зависимостей и повторным
запуском с уже подготовленным prefix. После холодной установки вновь прошли
функциональные тесты и проверка пакета. Из снимка удалены временный wheel venv,
архивы загрузок и expendable APT caches; остаются только рабочие зависимости (~68 MiB на диске).
