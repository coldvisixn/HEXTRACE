# Архитектура MVP

- `app.py`: Qt Widgets, панели QSplitter, навигация и пользовательские действия.
- `graph.py`: QGraphicsScene/View, карточки QGraphicsItem, рёбра и разовая раскладка.
- `store.py`: SQLite, параметризованные запросы, ограниченные страницы, WAL,
  связи проектов и объектов. UI и worker используют отдельные соединения.
- `scanner.py`: единственный QProcess без shell; проверка IP/портов; отмена с
  terminate/kill; XML разбирается в QThread; процессы не переживают запуск приложения.
- `nmapxml.py`: iterparse, Host/Service upsert; координаты существующих узлов
  сохраняются. Только открытые порты и наблюдаемые хосты получают confirmed.
- `scripts/build_deb.py`: deb all с системными зависимостями, desktop entry и SVG.

Модель: project → nodes / edges / tasks. Ручные Findings, Credential references,
Access и Notes — гипотезы до подтверждения пользователем. Эксплуатация не запускается.

Этапы: (1) модель и интерфейс, (2) сканирование и сохранение карты,
(3) функциональные тесты и пакет, (4) измерения и проверка в Kali,
(5) расширенные recon adapters и работа с большими графами.

Дорогие операции: сканер — QProcess, XML — QThread. UI загружает не больше 400
узлов и сохраняет ограниченный текст вывода. Раскладка выполняется по явной команде.
Полные результаты не держатся в Python памяти. Пакет не включает Python/Qt/Nmap.
